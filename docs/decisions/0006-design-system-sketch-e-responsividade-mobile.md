# Design System Sketch (Excalidraw) Monocromático e Navegação Mobile

A interface adota um tema escuro estilo sketch **estritamente monocromático** por padrão, com a fonte `Excalifont` aplicada globalmente em `UPPERCASE`, fundo principal `#121212`, superfícies/cards `#1e1e1e` e traços/textos claros `#f1f3f5` (e `#868e96` para itens secundários/concluídos). As cores semânticas suaves são restritas **exclusivamente** a dois pontos de toda a aplicação: (1) os blocos de horário na grade do **Calendário** (`#b2f2bb`, `#ffc9c9`, `#a5d8ff`, `#ffec99` para delimitar início e fim de cada agenda/reunião) e (2) o **círculo com seta** (`↑` verde `#b2f2bb` para entrada e `↓` vermelho `#ffc9c9` para saída) nas linhas da tabela de transações em **Finanças**. No desktop, a `Sidebar` é fixa à esquerda em layouts de 2 ou 3 colunas; em telas mobile (`< 768px`), a `Sidebar` converte-se em uma `Bottom Navigation Bar` fixa.
