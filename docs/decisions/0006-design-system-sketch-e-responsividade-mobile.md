# Design System Sketch (Excalidraw) Monocromático e Navegação Mobile

A interface adota um tema escuro estilo sketch **estritamente monocromático**, com a fonte `Excalifont` aplicada globalmente em `UPPERCASE`, **fundo único `#121212` em absolutamente todos os elementos** (página, sidebar, cards, modais e botões) e traços/textos claros `#f1f3f5` (com `#868e96` para itens secundários/concluídos). Todas as abas (exceto `Chat`) exibem o componente único padronizado `SketchAddButton` sempre com o texto `+ ADICIONAR` (`+` na frente). As cores semânticas suaves são restritas **exclusivamente** a dois pontos: (1) os blocos de horário na grade do **Calendário** (`#b2f2bb`, `#ffc9c9`, `#a5d8ff`, `#ffec99` para delimitar cada agenda) e (2) o **círculo com seta** (`↑` verde `#b2f2bb` para entrada e `↓` vermelho `#ffc9c9` para saída) nas transações em **Finanças**. No desktop, a `Sidebar` é fixa à esquerda; em telas mobile (`< 768px`), converte-se em `Bottom Navigation Bar` fixa.
