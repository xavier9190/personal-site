# Personal Site

## Agent skills

### Issue tracker

Issues and specs live as GitHub Issues in `xavier9190/personal-site` (with local fallback under `.scratch/` when `gh` CLI is unavailable). See `docs/agents/issue-tracker.md`.

### Triage labels

Default five canonical triage roles (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout (`GLOSSARY.md` at the repo root and ADRs in `docs/adr/` and `docs/decisions/`). See `docs/agents/domain.md`.
